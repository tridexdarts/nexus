Tridex Nexus – apt-Repository

Pakete für das Nexus-Board (Radxa CM3, Debian trixie, arm64).

Einrichten

curl -fsSLO https://dreide.github.io/nexus-apt/nexus-archive-keyring.deb
sudo apt install ./nexus-archive-keyring.deb
sudo apt update
sudo apt install nexus

Das Keyring-Paket installiert den Signaturschlüssel und /etc/apt/sources.list.d/nexus.sources. Danach kommen Updates mit sudo apt upgrade.

Die Installation über SSH per Kabel (eth0) ausführen: nexus-captive-portal übergibt wlan0 an NetworkManager, eine WLAN-Sitzung kann dabei abreißen.

Pakete

  • nexus – Metapaket, installiert alles Folgende
  • nexus-captive-portal – Hotspot mit Captive Portal (comitup)
  • nexus-web-panel – Befehle per Browser, Port 8080
  • nexus-web-terminal – Terminal im Browser (ttyd), Port 7681
  • nexus-archive-keyring – Schlüssel und apt-Quelle
