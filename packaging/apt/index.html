Tridex Nexus – apt repository

Packages for the Nexus board (Radxa CM3, Debian trixie, arm64).

Setup

curl -fsSLO https://tridexdarts.github.io/nexus-apt/nexus-archive-keyring.deb
sudo apt install ./nexus-archive-keyring.deb
sudo apt update
sudo apt install nexus

The keyring package installs the signing key and /etc/apt/sources.list.d/nexus.sources. After that, updates arrive with sudo apt upgrade.

Run the installation over SSH on Ethernet (eth0): nexus-captive-portal hands wlan0 over to NetworkManager, which can drop a Wi-Fi session.

Packages

  • nexus – metapackage, installs everything below
  • nexus-captive-portal – hotspot with captive portal (comitup)
  • nexus-web-panel – run commands from the browser, port 8080
  • nexus-web-terminal – terminal in the browser (ttyd), port 7681
  • nexus-archive-keyring – signing key and apt source
